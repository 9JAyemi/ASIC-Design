\section*{Finding clk\_per\_apr}
APR used the netlist synthesized at clk\_per\_syn = 0.396\,ns; only the APR clock period in
\texttt{var.tcl} was changed. From the 0.6\,ns run on, Innovus was restricted to SVT20 cells
(\texttt{setDontUse *LVT*}, \texttt{*BWP16P90*}) to match the Lab 2 synthesis; the first run
(0.396\,ns) had no restriction, and Innovus swapped most cells to LVT16. A 0.5\,ns run without the
restriction was also clean, but only because 530 cells were LVT16, so it does not count for SVT20.

At 0.396 and 0.6\,ns, Innovus met setup on paper only by upsizing the logic until it no longer fit
the core (``Density too high'' placement errors, about 200 DRC shorts and open signal nets).
Synthesis timed the design at the typical corner with ideal wires and clock; APR times it at the
slow corner with routed wires and a real clock tree, so the legal APR clock is longer.
0.7\,ns is the shortest period tested with a legal, routed, timing-clean layout.

\section*{Verification}
\begin{itemize}
\item \textbf{DRC} (\texttt{verify\_drc}): 28 violations, all VDD/VSS power stripes extending past the
die edge (``Out Of Die'', M2--M5) because the floorplan has no core margin.
\item \textbf{LVS} (\texttt{verifyConnectivity}): issues only on power: 92 unconnected well-tap
\texttt{VPP} pins and VDD/VSS segments; no signal net is open.
\item \textbf{Post-layout simulation}: \texttt{mult.apr.v} with \texttt{mult.sdf} (max delays)
and the Lab 2 testbench gives all five expected products (0x2, 0xc, 0x0, 0xfffe0001, 0x81b40),
each about 0.13--0.15\,ns after the clock edge.
\end{itemize}
